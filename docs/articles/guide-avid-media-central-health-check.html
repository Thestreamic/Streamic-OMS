How to Troubleshoot Avid MediaCentral UX: Step-by-Step

Official recommended procedure to troubleshoot MediaCentral UX — checking platform services, Interplay PAM and iNEWS connectivity, licensing, logs, and client-side cache.

By The Streamic Editorial Team · March 2026 · 14 min read

Reference: This guide follows the recommended troubleshooting procedure from Avid Knowledge Base article Recommended procedure to troubleshoot MediaCentral UX. Always check your MediaCentral version against the Avid compatibility matrix before applying procedures.

Stage 1: Verify Platform Services Status

All MediaCentral Platform Services (MCPS) must be running before you can begin diagnosing application-level issues. Log in to the MediaCentral server as Administrator.

Check MCPS via Management Console

  • Open a browser on the MCPS server and navigate to https://[server-hostname]/management.
  • Log in with your Administrator credentials.
  • Navigate to System → Services. All services should show a green status indicator.
  • If any service shows red or yellow, note the service name before proceeding.

Restart a Failed Service

  • Click the failed service name → click Stop, wait 10 seconds, then click Start.
  • For persistent failures: open a command prompt on the MCPS server and run net start "[Service Name]".
  • Check Windows Event Viewer (Application and System logs) for the service startup failure reason.

Stage 2: Verify Interplay PAM Connectivity

If users are experiencing missing assets or search failures, the Interplay PAM connection is the first place to check.

  • In the Management Console, go to Settings → Interplay Production.
  • Confirm the Interplay server hostname resolves correctly. Ping the Interplay server by FQDN from the MCPS server.
  • Check that the service account credentials are valid — expired passwords are the most common cause of Interplay disconnection.
  • Click Test Connection. A green checkmark confirms the connection is live.
  • If the test fails: verify port 1621 (Interplay Engine) is open between MCPS and Interplay. Check firewall rules on both servers.

Stage 3: Verify iNEWS Connectivity

  • Navigate to Settings → iNEWS in the Management Console.
  • Confirm iNEWS server hostname and port (default: 5672 for AMQP).
  • Click Test Connection. If it fails, check the iNEWS server is reachable on port 5672 from MCPS.
  • Verify the iNEWS service account has the correct read permissions on the iNEWS system database.

Stage 4: Check Licensing

  • In the Management Console, go to System → Licenses.
  • Verify that the number of active users does not exceed the licensed seat count.
  • Check the licence expiry date. Expired licenses cause login failures that look like authentication errors.
  • If licences are missing: contact your Avid reseller or check the Avid License Activation Centre at ilm.avid.com.

Stage 5: Review System Logs

  • From the Management Console: System → Logs → Download Logs. This exports a ZIP of all MCPS service logs.
  • Key logs to check: bus.log (message bus errors), acs.log (asset management), search.log (index errors).
  • Search for ERROR and FATAL entries around the time the issue was reported.
  • For Avid support cases, always include the full log bundle and the MCPS version number from System → About.

Stage 6: Clear Browser Cache (Client-Side)

Many MediaCentral UX display issues — missing thumbnails, stale layout, login loops — are caused by stale browser cache rather than a server fault.

  • Chrome: Settings → Privacy and security → Clear browsing data → select All time → tick Cached images and files and Cookies → Clear data.
  • Firefox: Settings → Privacy & Security → Cookies and Site Data → Clear Data.
  • After clearing, close all tabs, reopen MediaCentral UX, and log in fresh.
  • If the issue persists across browsers, the problem is server-side.

Pre-Air Checklist

  • ☑ All MCPS services green in Management Console
  • ☑ Interplay PAM connection test passes
  • ☑ iNEWS connection test passes
  • ☑ Licence count within limits, no expiry warnings
  • ☑ No ERROR or FATAL entries in logs from last 24 hours
  • ☑ Test story open/close and asset browse from a client workstation
  • ☑ Test MOS item insertion if running Vizrt or Ross graphics via MOS
