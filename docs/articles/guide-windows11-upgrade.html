Upgrading to Windows 11 on Broadcast Workstations

Step-by-step upgrade guide for broadcast workstations and edit suites. Hardware compatibility checks, NLE verification, driver handling, and rollback procedure.

By The Streamic Editorial Team · March 2026 · 8 min read

Before You Begin: Compatibility Check

Windows 11 requires TPM 2.0, Secure Boot, and a 64-bit CPU on the supported list. For broadcast workstations running NLE software (Avid, Premiere, DaVinci Resolve), NIC firmware, and GPU drivers, the upgrade path needs careful planning to avoid disrupting production.

Hardware Prerequisites

  • TPM 2.0: Open tpm.msc — Status should read "The TPM is ready for use." If not, enable in UEFI/BIOS under Security.
  • Secure Boot: Check in UEFI. Must be enabled for Win 11 upgrade to proceed.
  • CPU: Intel 8th Gen (Coffee Lake) or newer, or AMD Zen 2 or newer.
  • RAM: 4GB minimum, 16GB+ recommended for broadcast editing workstations.
  • Storage: 64GB minimum free on system drive. NVMe recommended for NLE cache.

Run the PC Health Check app (from Microsoft) to get a definitive pass/fail on your hardware before attempting the upgrade.

Step 1: NLE and Plugin Compatibility Audit

Before upgrading any broadcast workstation, verify that your NLE and critical plugins support Windows 11:

  • Avid Media Composer: v21.x and later support Windows 11. Check Avid's official compatibility matrix at avid.com for your exact version.
  • Adobe Premiere Pro: v22.0 (2022) and later support Windows 11. Older versions (2021 and prior) may have issues.
  • DaVinci Resolve: v17.4.3 and later. GPU driver compatibility is critical — verify your specific GPU model.
  • Telestream Vantage: Check Telestream's compatibility matrix. Vantage 8.x supports Windows Server 2019/2022; desktop clients need Win 11 verification.
  • GPU Drivers: Download the latest NVIDIA or AMD driver before upgrading. Older drivers may not install cleanly on Win 11.

Document every plugin, codec pack, and third-party driver installed on the machine before upgrading. Create a spreadsheet with version numbers and vendor support status.

Step 2: Backup and Snapshot

  • Create a full system image backup using Windows Backup or a third-party tool (Acronis, Macrium Reflect).
  • Export your NLE project files and media cache settings.
  • Note your network share mappings, Avid Interplay credentials, and storage area network (SAN) client configuration.
  • Screenshot your GPU and NIC driver version numbers from Device Manager.

Step 3: Perform the Upgrade

  1. Download the Windows 11 Installation Assistant from microsoft.com/software-download/windows11.
  2. Run as Administrator. The tool will check eligibility and begin the download.
  3. Select Keep my files and apps when prompted.
  4. Allow 45–90 minutes for the upgrade to complete. The machine will reboot 2–3 times.
  5. Do not interrupt power during the process.

Step 4: Post-Upgrade Verification

  • GPU drivers: Open Device Manager — if the GPU shows a yellow warning, reinstall the driver from the vendor site.
  • NIC / network: Verify all network shares reconnect. Re-map any drives that dropped.
  • Avid / Premiere: Launch your NLE and open a test project. Check that media links resolve correctly.
  • Audio devices: Verify Pro Tools or your DAW sees all audio interfaces. ASIO drivers may need reinstalling.
  • Activation: Windows 11 should activate automatically using your existing Windows 10 digital license.

Rollback Procedure

Within 10 days of the upgrade, you can roll back via Settings → System → Recovery → Go back. After 10 days, use your system image backup to restore. Always test upgrades on a non-production machine first before rolling out to edit suites.
