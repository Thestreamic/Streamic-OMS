How to Integrate Vizrt Graphics with Avid MediaCentral and iNEWS

Connecting Vizrt's real-time graphics engine to Avid's newsroom and production systems enables journalists to control lower-thirds and fullscreens directly from the iNEWS rundown — without touching the graphics workstation. This guide covers the full integration.

By The Streamic Editorial Team · March 2026 · 14 min read

Architecture Overview

The Vizrt–Avid integration operates through two connection layers:

  • Vizrt Plugin for MediaCentral: A MediaCentral panel that allows browsing and previewing Viz template graphics from within MediaCentral Cloud UX
  • Viz Gateway / MOS Gateway: A MOS (Media Object Server) protocol bridge that connects Viz Engine templates to iNEWS stories, enabling story-driven graphics playout from the rundown

Both connections are required for a full broadcast newsroom integration. The plugin alone provides browsing; the MOS Gateway adds the critical story-driven automation.

Prerequisites

  • Viz Engine 4.x or later (with Viz Pilot or Viz Trio for template control)
  • Avid MediaCentral Platform Services 2023.x or later
  • iNEWS 9.x or later with MOS capability enabled
  • Network connectivity: MCPS server must reach Viz Engine on TCP 6100 (Viz Engine default port) and TCP 10540 (MOS port)

Step 1: Install the Vizrt Plugin for MediaCentral

  1. Download the Vizrt Plugin installer from the Vizrt Customer Portal (requires Vizrt support contract)
  2. Run the installer on the MediaCentral Platform Services server — not a client workstation
  3. After installation, navigate to MCPS Admin → Plug-ins → Installed Plug-ins
  4. Verify Vizrt Graphics Plugin appears with status Active
  5. Restart MCPS Core service: sudo systemctl restart avid-mcs

Step 2: Configure the Viz Engine Connection in MCPS

  1. In MCPS Admin, go to Connections → Add Connection → Vizrt
  2. Enter the Viz Engine hostname or IP
  3. Set Port: 6100 (Viz Engine REST API port)
  4. Set Protocol: HTTP (or HTTPS if your Viz Engine has TLS configured)
  5. Click Test Connection — you should see a list of Viz template folders returned
  6. Assign the connection to your MediaCentral user group — only users in enabled groups will see the Vizrt panel

Viz Engine Port Reference

  • TCP 6100: Viz Engine REST API (template browsing, preview)
  • TCP 6800: Viz Engine control interface (for Viz Pilot)
  • TCP 10540: MOS gateway port (iNEWS MOS object handling)
  • UDP 50002: Viz Engine render output (video)

Step 3: Configure the MOS Gateway (iNEWS Integration)

The MOS Gateway enables iNEWS journalists to embed Viz graphic items directly inside story slugs. When a story goes to air, the graphics fire automatically via the MOS protocol.

  1. On the Viz Pilot server, open Viz Pilot Edge → MOS Settings
  2. Set NCS Host to your iNEWS server IP or hostname
  3. Set MOS ID — this must match exactly the MOS ID configured in iNEWS. Typically formatted as: VIZRT.NEWSROOM01
  4. Set Port: 10540 (iNEWS default MOS port)
  5. Click Connect — the iNEWS MOS Active indicator should turn green

Step 4: Configure iNEWS for MOS

  1. In iNEWS System Configuration, open MOS Configuration
  2. Add a new MOS device with the MOS ID matching your Viz Pilot Edge setting
  3. Set Active MOS Connection: Enabled
  4. Assign the MOS device to your production database
  5. Verify: open a rundown in the iNEWS client and confirm the Vizrt MOS plugin appears in the story editor toolbar

Step 5: Test the End-to-End Workflow

  1. In iNEWS, create a test story. Click the Vizrt graphic icon in the toolbar.
  2. Browse and select a lower-third template. Fill in the name and title fields.
  3. Save the story. The MOS item should appear as a graphic cue in the rundown.
  4. In MediaCentral, open the same story — verify the Vizrt graphic preview renders in the MediaCentral Vizrt panel.
  5. On the Viz Engine, trigger the cue manually via Viz Trio. Confirm the graphic appears on the Viz output.

Troubleshooting Common Integration Issues

MOS items not appearing in iNEWS

Check that the MOS ID in Viz Pilot Edge exactly matches the MOS ID in iNEWS configuration — including capitalisation and punctuation. A single character difference causes silent MOS connection failure.

Template thumbnails not showing in MediaCentral

The MCPS-to-Viz Engine TCP 6100 connection may be blocked by a firewall. Confirm with: telnet [viz-engine-ip] 6100 from the MCPS server. If it times out, raise a firewall rule with your network team.

Graphics fire at wrong timecode

iNEWS sends MOS active commands on story transition, not on item timecode. If your facility requires timecode-accurate graphic firing, use Viz Pilot with a rundown control surface rather than iNEWS MOS alone.

Recommended Integration Testing Checklist

  • Viz Engine TCP 6100 accessible from MCPS server ✓
  • Viz Pilot MOS Gateway connected to iNEWS (green indicator) ✓
  • Template thumbnails browse correctly in MediaCentral Vizrt panel ✓
  • MOS graphic item creates correctly in iNEWS story ✓
  • Test graphic fires on Viz Engine output on rundown transition ✓
  • Failover tested: Viz Engine secondary (if configured) activates on primary failure ✓
