How to Clear Cache in Avid MediaCentral Cloud UX (2025)

MediaCentral Cloud UX stores substantial cache data in both the browser and its server-side layer. When stories load incorrectly, thumbnails appear stale, or playback fails, a structured cache clear resolves most issues without requiring IT support.

By The Streamic Editorial Team · March 2026 · 7 min read

Understanding MediaCentral Cloud UX Cache Layers

MediaCentral Cloud UX operates across three cache layers that can each cause issues independently:

  • Browser cache: Stores JavaScript bundles, CSS, and static assets. Stale browser cache causes UI glitches and failed module loads.
  • Application session cache: Stores user layout preferences, panel states, and open story data. Corrupted session cache causes the application to open in a broken state.
  • Proxy and thumbnail cache (server-side): Managed by the Interplay Production Web Services layer. Stale here causes outdated thumbnails and incorrect sequence previews.

Step 1: Clear Browser Cache (First Step, Always)

Most MediaCentral display issues are resolved at the browser level. MediaCentral Cloud UX is certified for Chrome and Firefox — use Chrome in incognito mode as a quick diagnostic step before clearing.

  1. In Chrome: press Ctrl+Shift+Delete (Windows) or Cmd+Shift+Delete (Mac)
  2. Set time range to All time
  3. Check: Cached images and files, Cookies and other site data
  4. Click Clear data
  5. Hard-reload MediaCentral: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)

Step 2: Clear MediaCentral Application Cache

If the browser clear does not resolve the issue, clear the application-level cache from within MediaCentral:

  1. Log in to MediaCentral Cloud UX
  2. Click your username (top-right) → User Settings
  3. Navigate to System → Restore Defaults
  4. Click Reset Layout — this clears saved panel positions and custom workspace configurations
  5. Log out and log back in

Alternative: URL-Based Cache Reset

Append ?cache=clear to your MediaCentral URL to force an application-level cache flush on load. This is useful when you cannot access User Settings due to a UI fault.

https://your-mediacentral-server/app/app?cache=clear

Step 3: Clear Server-Side Proxy Cache

Stale thumbnails and proxy previews are managed server-side. This requires access to the MediaCentral Platform Services administrator panel:

  1. Navigate to https://[your-server]:443/api/als/v0 to confirm Avid License Services is running
  2. Log in to the Interplay | Production Web Services admin console
  3. Go to Asset Management → Proxy Cache → Clear Stale Proxies
  4. Select the affected asset folder or sequence and click Regenerate Proxies

Note: Regenerating proxies is a background job. Large media libraries may take 30–60 minutes to fully refresh.

Step 4: Clear MediaCentral UX Persistent Storage (Advanced)

For persistent issues not resolved by the above steps, clear Chrome's site-specific storage:

  1. In Chrome, go to Settings → Privacy and security → Site settings
  2. Search for your MediaCentral server URL
  3. Click the site → Delete data
  4. This removes IndexedDB, localStorage, and service worker caches specific to MediaCentral
  5. Re-login — you will need to re-authenticate and reconfigure your workspace

When Cache Clear Doesn't Fix It

If clearing all cache layers does not resolve the issue, the problem is likely server-side:

  • Playback black screen: Check the Interplay Transfer Engine service status. Proxy generation may have failed for the specific asset.
  • Stories not loading: Check the iNEWS connection status in MediaCentral System Settings. A dropped iNEWS connection shows stale story data regardless of cache state.
  • Slow thumbnails: Check your MediaCentral server disk I/O. Proxy cache is stored on the server filesystem — a nearly-full volume causes degraded thumbnail service.
  • Login loop: SSO token expired. Clear cookies and re-authenticate against your domain controller.

Recommended Maintenance Schedule

  • Clear browser cache weekly on workstations used for live production
  • Reset proxy cache monthly or after major Avid version upgrades
  • Monitor server disk usage — keep proxy storage volume below 75% capacity
  • After MediaCentral upgrades, force a full browser cache clear on all client workstations before users log back in
