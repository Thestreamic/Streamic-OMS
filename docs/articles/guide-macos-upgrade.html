Upgrading to macOS Sequoia on Post-Production Macs

How to safely upgrade a post-production Mac to macOS Sequoia. NLE compatibility matrix, plugin audit, audio interface handling, and what to do if plugins break.

By The Streamic Editorial Team · March 2026 · 9 min read

Overview: macOS Sequoia for Broadcast and Post

macOS Sequoia (15.x) introduced significant changes to system security, GPU driver architecture (Metal 3), and USB audio handling that directly affect broadcast and post-production environments. This guide covers the safe upgrade path for edit suites, audio suites, and graphics workstations.

Step 1: Pre-Upgrade Compatibility Check

NLE Compatibility Matrix

  • Avid Media Composer: v23.x and later officially support macOS Sequoia. Earlier versions: check Avid's compatibility chart at avid.com/resource-center. Media Composer 2022 and prior are not supported on Sequoia.
  • Adobe Premiere Pro / After Effects: Version 24.0 (2024) and later support Sequoia. Creative Cloud will alert you if your version is incompatible.
  • DaVinci Resolve: Version 18.6.4 and later. Apple Silicon users should ensure they have the ARM-native version installed.
  • Pro Tools: Version 2023.9 or later supports Sequoia. Older versions have known compatibility issues with Core Audio on macOS 15.
  • Telestream Wirecast / Switch: Check telestream.net for your specific version's Sequoia compatibility.

Step 2: Third-Party Plugin Audit

macOS Sequoia tightened Gatekeeper enforcement. Plugins signed with older developer certificates may fail. Before upgrading:

  • List all installed plugins (AAX for Pro Tools, AU/VST for Logic/Nuendo, OFX for Resolve).
  • Check each vendor's website for a Sequoia-compatible version.
  • Download updates before upgrading — some vendors gated Sequoia support behind paid updates.
  • Avid NEXIS client: Download the latest client software from Avid downloads — older NEXIS clients do not reconnect reliably after a macOS major version upgrade.

Step 3: Backup

  • Create a Time Machine backup to an external drive or NAS.
  • Export Avid project settings, bins, and user profiles.
  • Note your audio interface firmware version (MOTU, Apogee, Universal Audio, RME).
  • Screenshot all DAW I/O configurations and routing.

Step 4: Perform the Upgrade

  1. Go to System Settings → General → Software Update.
  2. Click Upgrade Now next to macOS Sequoia.
  3. Allow 30–60 minutes. Apple Silicon Macs are significantly faster than Intel.
  4. The Mac will restart 1–2 times during the process.

Step 5: Post-Upgrade Verification

  • Audio interfaces: macOS 15 changed USB audio class handling. If your interface isn't detected, install the vendor's latest driver, or toggle the USB port.
  • Avid NEXIS: Open NEXIS client and verify workspace mounts. Re-authenticate if required.
  • Pro Tools: Launch Pro Tools and open a session. Check all AAX plugins load. Go to Help → Diagnostics → Run to identify any failed plugins.
  • DaVinci Resolve: Open Preferences → Memory and GPU → confirm GPU is listed and Metal is selected.
  • Premiere / Media Encoder: Check that all media encoder codecs are available. Apple ProRes rendering should work natively.

Known Issues on Sequoia for Broadcast

  • AJA / Blackmagic capture cards: Require driver updates specific to Sequoia. Check aja.com and blackmagicdesign.com for the latest macOS 15 drivers before upgrading.
  • Logic Pro: Fully supported. All Apple-native plugins updated automatically.
  • Older USB audio interfaces: Class-compliant devices generally work. Devices using custom kext drivers may not — contact the manufacturer.
