Studio-Grade DI Pipeline (2026): ARRI, RED, Sony VENICE 2, ACES 1.3 & Dolby Vision

STUDIO‑GRADE DI PIPELINE (2026 EDITION)

Optimized for ARRI ALEXA 35, RED V‑RAPTOR 8K, Sony VENICE 2, ACES 1.3, HDR10+, Dolby Vision, IMF Delivery

1. Overview

The Digital Intermediate (DI) pipeline is the heart of modern post‑production. It ensures that footage captured on set is transformed into a polished, color‑accurate, HDR‑ready master suitable for theatrical, OTT, broadcast, and archival delivery.

This workflow reflects 2026 global standards, including:

  • ACES 1.3 color management
  • Dolby Vision 5.1 HDR metadata
  • HDR10+ dynamic metadata
  • OpenEXR 16‑bit linear archive masters
  • 8K RAW native pipelines
  • AI‑assisted Quality Control

2. Camera Originals & On‑Set Data Management

The pipeline begins with the acquisition of raw data from the industry’s leading sensor technologies.

📦 Data Workflow

  • Dual Checksum Copy: Verify all media using ShotPut Pro, Silverstack, or hedge.
  • LTO‑9 Archival Backup: Deep, persistent, off-site storage.
  • Cloud Mirror Backup: Immediate sync to secure object storage (AWS S3 / Wasabi).
  • On-Set Grading: Generate color decision lists (CDL) + display look-up tables (LUTs).
  • Reporting: Automate creation of camera & sound reports.

3. Dailies Creation

Efficient proxy generation is critical for maintaining an effective editorial schedule.

🎛️ Processing

  • Color Pipeline: Apply ACES Input Transform (IDT) for camera-specific linear space.
  • Display Match: Apply show LUT or on‑set CDL for review.
  • Sync Audio: Confirm synchronization of all original audio tracks.
  • Generate Proxies: Create lightweight editorial-ready files.

📤 Deliverables

  • Editorial (Offline): DNx36 (HD) or ProRes Proxy (HD/4K).
  • Review (Remote): Upload to PIX, Frame.io, or Moxion for client review.
  • Dailies Color: ProRes 4444XQ for critical color verification.

4. Editorial Workflow

While creative decisions happen here, metadata integrity must be preserved.

  • Offline Edit: Construct the story in Avid Media Composer, Adobe Premiere, or FCP.
  • Metadata Integrity: Maintain all camera tape names, clip numbers, and sound TC.
  • Picture Lock: Finalize the cut and export conformed deliverables: AAF, EDL, or XML.
  • Reference QuickTime: Provide a visual reference QT with timecode and guide tracks.

5. Conform (Online Editing)

The process of relinking the offline edit back to the original full-resolution camera RAW (ARRIRAW, R3D, X-OCN, BRAW).

Primary Tools: DaVinci Resolve Studio 19, Baselight v6, or SGO Mistika.

🔧 Tasks

  • RAW Relink: Reconnect the AAF/XML timeline to the camera originals.
  • Apply ACES 1.3: Configure the conformed timeline as an ACES Scene‑Referred pipeline.
  • Online Edit: Manually resize, reframe, or stabilize shots to match the reference QT.
  • Dead‑Pixel & Sensor Repair: Use specialized AI tools to repair dead pixels and sensor noise.
  • VFX Pulls: Export OpenEXR 16‑bit linear sequences for VFX.

6. VFX Workflow

Standardizing the color pipeline for VFX ensures seamless integration during the grading process.

🎨 Color Space

  • ACEScg: The 2026 industry standard for all CGI, compositing, and rendering.

📁 Deliverables

  • Plates: OpenEXR 16‑bit linear (without the show LUT applied).
  • Mattes: Include Cryptomatte channels for precise color isolating.
  • Handles: 8–16 frame handles must be included on all shots.
  • Comps: Return all comps as OpenEXR with appropriate OCIO metadata embedded.

7. Color Grading

The core creative transformation of the image, executed with 1,000+ nit accuracy.

🎚️ Primary Grade

  • Scene‑Referred Grading: Apply grading decisions within the ACES 1.3 linear space.
  • HDR Grading First: Perform the master grade for the primary delivery format (e.g., Dolby Vision).
  • SDR Trims: Use automated metadata mapping to perform efficient SDR (Rec.709) trims.

🖥️ Tools

  • Baselight v6
  • DaVinci Resolve Studio 19
  • Mistika Boutique

🎞️ Creative Passes

  • Texture Management: Diffuse highlights and manage skin tone textures.
  • Film Emulation: Apply verified emulation profiles (e.g., Kodak 2383, Fuji Eterna).
  • Grain Pass: Composite stylized film grain or sensor noise.
  • Beauty Cleanup: Perform final beauty or cleanup VFX.

8. Mastering & Deliverables

Creation of the highest possible quality masters and the derived distribution files.

🎬 Primary Archive Master

  • 4K/8K OpenEXR ACES Archive Master (NAM): A master archive containing all final conformed and graded OpenEXR 16‑bit half-float frames.
  • OCIO Metadata: Must include complete OpenColorIO metadata for accurate restoration.

🔊 Audio Mastering

  • Primary: 5.1 / 7.1 / Dolby Atmos ADM BWF.
  • Compliance: Meet international loudness compliance (eBU R128 or ATSC A/85).

9. Quality Control (QC)

A strict automated and manual verification process to ensure flawless masters.

🧪 Automated QC

  • Dead Pixels: Scan for and flag single pixel failures.
  • Frame Drops: Identify missing or repeated frames.
  • Color Mismatches: Verify that the output matches the required color space (e.g., P3 vs Rec.2020).
  • HDR Validation: Ensure Dolby Vision/HDR10+ metadata maps correctly without clipping.

👁️ Manual QC

  • Artifact Review: Visually check for compression artifacts or grade errors.
  • Subtitle Sync: Confirm that all timed text lines match the audio.
  • Color Continuity: Perform final scene-to-scene color continuity checks.
  • Audio Phase: Ensure audio phase is aligned across all tracks.

10. Final Delivery & Archival

The safe preservation of the final masters for the commercial life of the project.

  • LTO‑9 Dual Backup: Store dual copies on different LTO tapes, with one stored off-site.
  • Cloud Archival: Immediate sync of critical masters to AWS Glacier Deep Archive.
  • Metadata Manifest: Include a comprehensive JSON/XML manifest detailing every asset.
  • Versioning & Checksum: All final deliverables must include SHA-256 checksum logs for future verification.
