Adobe Premiere Pro to Avid Media Composer: The Complete Interchange Workflow

Moving sequences between Premiere and Avid without losing grades, effects, or metadata is one of the most common challenges in post-production. This guide covers every reliable method.

By The Streamic Editorial Team · March 2026 · 8 min read

Why This Workflow Exists

Many productions originate in Premiere Pro — particularly news, documentary, and corporate content — but finishing, colour correction, or broadcast delivery requires Avid Media Composer. The reverse is also common: Avid offline to Premiere online for Lumetri grading. Neither NLE speaks the other's native format, so a structured interchange workflow is essential.

Method 1: AAF Export (Recommended for Most Workflows)

AAF (Advanced Authoring Format) is the broadcast-standard interchange container. It preserves cuts, audio levels, clip names, and some effects metadata.

From Premiere Pro:

  1. Select your sequence in the Project panel. Do not open it in the Timeline.
  2. Go to File → Export → AAF.
  3. In the Export AAF dialog, choose these settings:
    • Export Method: Copy all media (if you want self-contained AAF) or Link to media for reference only
    • Sample Rate: Match your project (48 kHz for broadcast)
    • Render audio clip effects: Yes, if you have heavy processing
    • Mixdown video: Leave unchecked unless Avid cannot read the source codec
  4. Name the AAF and save it to a shared storage location accessible to both systems.
Tip: If your project uses multicam sequences or dynamic links to After Effects, flatten these before export. AAF cannot represent these dependencies and will silently drop them.

Import into Avid Media Composer:

  1. Create a new bin in Media Composer.
  2. Go to File → Get Bin from AAF/OMF.
  3. Navigate to your AAF file and click Open.
  4. In the Link/Consolidate dialog, choose Consolidate if you want Avid to manage the media, or Link to reference the existing files in place.
  5. Set your target drive to your Avid media drive or ISIS/NEXIS workspace.
  6. Avid will import the sequence and all referenced clips into the new bin.
Known limitation: Premiere colour grades (Lumetri) do not transfer via AAF. Export a CDL XML or grade reference frame if colour context matters for the Avid editor.

Method 2: EDL (For Simple Cut-Only Sequences)

EDL (Edit Decision List) is simpler than AAF but only preserves cuts and basic transitions. Use this when AAF is overkill — such as a straightforward interview cut with no effects.

  1. In Premiere: File → Export → Final Cut Pro XML and then convert using Assisted Editing or use File → Export → EDL directly (CMX 3600 format).
  2. In Avid: File → Input → Import → EDL. Map your reel names to the corresponding Avid bins.

Method 3: Avid Direct Link (AMA/MediaLink)

If you're running Avid 2020 or later and have shared storage, Avid's Direct Link allows Media Composer to link directly to Premiere-managed media without transcoding.

  1. Ensure both Premiere and Media Composer are pointed at the same shared storage path.
  2. In Media Composer: File → Link to AMA File(s). Navigate to the camera originals or Premiere-managed media.
  3. Import the AAF from Premiere. Avid will relink automatically if the file paths match.

Codec Compatibility Checklist

Before any interchange, verify that Media Composer can read your source format natively:

  • DNxHD/DNxHR: Native in both — ideal interchange codec
  • ProRes (Mac): Native in Premiere; requires Avid codec pack on Windows
  • H.264/H.265: Both read it, but transcode to DNxHD first for performance
  • XDCAM: Both support natively — no action required
  • RED R3D: Requires AMA plugin in Avid; works natively in Premiere

Audio Mapping

Avid and Premiere handle audio tracks differently. Premiere's adaptive audio model flattens to discrete mono tracks on AAF export. Before export, verify your audio layout — a stereo pair in Premiere exports as two mono tracks in Avid. Label tracks clearly (e.g. A1/A2 for dialogue, A3/A4 for music) to simplify Avid relink.

Broadcast tip: For delivery to broadcast, use DNxHD 145 8-bit as your interchange codec. It is universally supported, royalty-free, and produces predictable results across both platforms without the licensing complexity of ProRes on Windows.

Troubleshooting Common Issues

  • Missing media after import: Check that your AAF references the correct drive letter/path. Avid stores absolute paths — if the drive mapping differs between machines, relink manually.
  • Audio sync drift: Almost always a frame-rate mismatch. Confirm both projects are set to the same frame rate (e.g. 25fps, not 29.97fps vs 30fps).
  • Effects showing as unrendered: Expected — Premiere effects do not translate. Plan a regrade in Avid's Symphony or export a reference grade as a LUT.
  • Sequence duration mismatch: Usually caused by Premiere sequences with mixed frame rates. Conform to a single frame rate before AAF export.
