Vantage Workflow: Transcoding and Delivering to AWS S3 for Cloud Distribution

Once your Vantage NAS workflow is running, adding an S3 delivery path takes under 30 minutes. This guide covers S3 bucket configuration, IAM credentials, and the Vantage Copy action that makes it work.

By The Streamic Editorial Team · March 2026 · 9 min read

Prerequisites

  • Working Vantage 8.x installation with the Cloud or Copy action licence
  • Vantage Transcode workflow already built (see Part 1: NAS Transcode Workflow)
  • AWS account with an S3 bucket created in your target region
  • AWS IAM user with s3:PutObject and s3:GetBucketLocation permissions

Step 1: Create an IAM User and Access Key

  1. In the AWS Console, navigate to IAM → Users → Add users.
  2. Name the user vantage-s3-delivery and select Programmatic access only.
  3. Attach the policy AmazonS3FullAccess (or a custom policy scoped to your specific bucket — preferred for production).
  4. On completion, download the .csv containing the Access Key ID and Secret Access Key. Store these securely — AWS will not show the secret key again.

Scoped bucket policy (recommended for production):

{{
  "Version": "2012-10-17",
  "Statement": [{{
    "Effect": "Allow",
    "Action": ["s3:PutObject", "s3:GetObject", "s3:DeleteObject",
               "s3:GetBucketLocation", "s3:ListBucket"],
    "Resource": [
      "arn:aws:s3:::your-bucket-name",
      "arn:aws:s3:::your-bucket-name/*"
    ]
  }}]
}}
Security: Never use your AWS root account credentials in Vantage. Always create a dedicated IAM user with the minimum required permissions. Rotate the access key every 90 days.

Step 2: Register S3 as a Vantage Storage Location

  1. Open Vantage Management Console → Storage.
  2. Click Add and select storage type Amazon S3.
  3. Enter:
    • Name: AWS_S3_Delivery
    • Bucket name: your-bucket-name
    • Region: e.g. eu-west-1 for Ireland
    • Access Key ID: paste from your IAM CSV
    • Secret Access Key: paste from your IAM CSV
    • Path prefix: media/output/ (optional — organises files within the bucket)
  4. Click Test Connection. Vantage will attempt a list operation on the bucket. A green tick confirms connectivity.

Step 3: Add S3 Output to Your Existing Workflow

Open your existing NAS transcode workflow in Workflow Designer.

  1. After the Transcode action, add a Copy action.
  2. In the Copy action configuration:
    • Source: The output media variable from the Transcode action (e.g. {MediaNickname})
    • Destination storage: AWS_S3_Delivery
    • Filename: {OriginalFilename}_{DateTime}_MP4.mp4 — the timestamp prevents overwriting on re-delivery
    • Storage class: STANDARD for active delivery; STANDARD_IA for archive
  3. Optionally add a second Copy action in parallel (not in series) to deliver simultaneously to both NAS and S3.

Step 4: Parallel NAS + S3 Delivery

For production workflows, deliver to both destinations simultaneously rather than sequentially. This prevents S3 upload latency from delaying local NAS availability.

  1. In Workflow Designer, connect the Transcode action output to two separate Copy actions.
  2. Copy Action A → NAS output (as built in Part 1)
  3. Copy Action B → S3 output (as built above)
  4. Both run in parallel. A Synchronise action after both can trigger a final notification once both deliveries confirm.
Cost tip: S3 egress charges apply when data is read out of AWS. If you're uploading for distribution via CloudFront or MediaPackage, ensure your S3 bucket and CloudFront distribution are in the same AWS region to minimise inter-region transfer costs.

Step 5: Test and Validate

  1. Drop a test file into your NAS ingest hot folder.
  2. Monitor the job in Vantage Job Status — both Copy actions should appear as sub-tasks.
  3. In the AWS S3 Console, navigate to your bucket and confirm the file has arrived in the media/output/ prefix.
  4. Download a copy from S3 and validate using MediaInfo — confirm codec (H.264), bitrate, and audio layout match your Transcode configuration.

Monitoring and Alerting

  • Enable AWS S3 Event Notifications on your bucket to trigger downstream processing (e.g. Lambda for MediaConvert, SNS for alerts) when Vantage delivers a new file.
  • In Vantage, configure the workflow's notification action to include the S3 object URL in the delivery confirmation email.
  • Set up AWS CloudWatch metrics on your S3 bucket to monitor upload volumes and detect delivery failures.
