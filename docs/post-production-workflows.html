Studio-Grade Video Post-Production Workflow

1

Pre-Production

Plan the content, visuals, and technical requirements before a single frame is captured

  • Scriptwriting & revisions
  • Storyboard creation
  • Shot list development
  • Location scouting & planning
  • Equipment list & hire
  • Production schedule
  • Metadata templates (scene, shot, take)

Key output: Approved script, signed-off storyboard, complete metadata schema documented before production begins. Metadata templates defined here propagate through the entire pipeline — changes downstream cost exponentially more.

2

Production (Shooting)

Capture high-quality footage with proper metadata and on-set data management

Camera & Capture

  • Camera setup: ARRI, RED, Sony, Blackmagic
  • Lighting setup & gaffer coordination
  • Audio recording (SFX + dialogue)
  • Slate + metadata logging per take
  • On-set monitoring (DIT station)

Data Management On-Set

  • Dual checksum copy (primary SSD + backup SSD)
  • LTO-9 near-set backup where applicable
  • Generate on-set LUTs + CDL per scene
Critical: Never rely on a single copy. Two physically separate media, verified checksums, before the camera crew wraps for the day. Data loss at this stage is unrecoverable.
3

Ingest & Data Management

Secure, organise, and prepare footage for editorial

  • Dual checksum copy to facility storage
  • Structured folder hierarchy creation
  • Proxy generation (DNxHD 36 or ProRes Proxy)
  • Metadata verification & MAM ingest
  • Cloud backup to primary cloud tier
  • LTO archival of camera originals

4

Editorial (Offline Edit)

Build the story using lightweight proxies — performance over resolution

  • Rough cut assembly
  • Fine cut refinements
  • Picture lock approval
  • Export AAF / EDL / XML for conform
  • Reference QuickTime for VFX pulls

Tools in use: Avid Media Composer (AAF workflows), Adobe Premiere Pro (XML/EDL), DaVinci Resolve (integrated finish workflows). Proxy format must match the conform system’s expectations — verify before picture lock.

Picture lock discipline: Changes after picture lock propagate through colour, VFX, audio, and mastering simultaneously. Each downstream department must approve any post-lock change before it is executed.

5

Conform (Online Edit)

Rebuild the film at full-quality RAW, linked to camera originals

  • Relink to camera RAW via AAF/EDL/XML
  • Apply ACES 1.3 colour managed pipeline
  • Optical stabilisation where required
  • Reframing & repositioning shots
  • Dead-pixel & sensor artifact repair
  • VFX pulls (OpenEXR 16-bit with handles)
ACES 1.3 pipeline: All footage ingested via the appropriate IDT (Input Device Transform) for each camera. Grade occurs in ACEScct working space. Output via RRT + ODT for each deliverable colour space. Switching ACES versions mid-project invalidates all prior colour work.

7

VFX Integration

Insert CGI, compositing, and motion graphics into the colour-managed timeline

  • ACEScg working colour space for all CG
  • EXR plates delivered from conform with handles
  • Cryptomatte for object-level compositing control
  • 8–16 frame handles on all VFX pulls
  • Final comps returned as EXR (32-bit float)

9

Quality Control

Automated and manual QC to ensure every master is technically flawless

▲ Automated QC

  • Frame drops & duplication detection
  • HDR metadata validation (MaxCLL, MaxFALL)
  • Colour space mismatch flagging
  • Audio clipping & loudness (EBU R128)

■ Manual QC

  • Artifact & compression review
  • Subtitle sync verification
  • Colour continuity across scenes
  • Final reference playback on calibrated display

Tools: Venera Pulsar (automated QC), Tektronix Sentry (monitor), Interra ORION (OTT QC), Colorfront (HDR reference monitoring), Dolby Vision Analyser.

Pass/fail criteria: Zero frame drops, HDR metadata within spec per platform requirements (Netflix QC checklist, Amazon IMF specification), audio LUFS within ±1dB of target, subtitles synced to ±1 frame.

10

Archival

Preserve the project for decades — minimum dual-copy, geographically separated

  • LTO-9 dual-copy backup (separate physical locations)
  • Cloud archival via AWS Glacier or Azure Archive
  • Metadata manifest & asset inventory
  • Version logs & decision records
Archive LayerTechnologyRecovery TimeCost / TB / month
On-site (primary)LTO-9 tape libraryHours~$1.50
Off-site (secondary)LTO-9 vault rotation1–3 days~$2.00 (inc. transport)
Cloud cold (tertiary)AWS Glacier Deep Archive12–48 hours~$0.002

Restore testing: Archive integrity must be verified annually via full restore test of a randomly selected project. Checksums recorded at archival must match on restore. Tape media has a finite read-cycle lifespan — migration to new LTO generation is required every 7–10 years.
