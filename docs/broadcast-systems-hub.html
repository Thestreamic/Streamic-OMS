What is this page?

Broadcast facilities use dozens of specialised software and hardware tools — each doing a very specific job. This page lists 57 of the most widely used systems in the industry. For each one, we explain what it does in simple terms, what other systems it connects to, and any important things engineers need to know when setting it up. On-Air Graphics & Newsroom Automation

4 systems

These systems create and display the text, animations, and data graphics you see on screen during a news bulletin or sports programme — score tickers, name captions, weather maps, and transition animations.

VizrtReal-Time Graphics
Viz Pilot & Viz Engine
What it does: Vizrt is the dominant graphics system used in tier-1 television news and sport worldwide. Viz Engine is the rendering hardware/software that actually draws graphics in real time (it generates them frame-by-frame as they appear on screen, not pre-rendered). Viz Pilot is the operator interface where journalists fill in graphic templates — for example, typing a person's name into a lower-third caption. The two connect to the newsroom system (NRCS) via a standard protocol called MOS so graphics are triggered directly from the broadcast rundown.

Channel Playout & Broadcast Automation

6 systems

Playout is the process of broadcasting a channel's schedule — playing programmes, advertisements, and continuity content in the correct order. These systems automate what would otherwise require a team of operators running a channel 24 hours a day.

Pebble Beach SystemsChannel Playout
Lighthouse Automation
What it does: Lighthouse is a broadcast automation system — software that runs a TV channel's schedule automatically. It receives the day's schedule from a traffic (scheduling) system, checks all the video files are ready, and plays them out in the correct order at the correct times. It controls the playout server hardware that actually outputs the video signal to the transmitter. Used by commercial broadcasters where running to the second timing is essential for advertising revenue.

Encoding, Quality Control & Cloud Delivery

12 systems

Before video reaches viewers, it must be converted into the right format and quality-checked. These systems handle the conversion (encoding/transcoding) and automated checking (QC) of broadcast content.

TelestreamTranscoding / Workflow
Vantage Media Processing
What it does: Vantage is a workflow automation and transcoding platform. Transcoding means converting a video file from one format to another — for example, converting a camera's raw file into the format a streaming platform requires, or creating several versions at different quality levels (called an ABR ladder) for adaptive streaming. Vantage manages these jobs automatically using visual workflow diagrams, watching folders for new files and processing them as they arrive.

Venera TechnologiesAutomated QC
Pulsar File-Based QC
What it does: Quality control (QC) is the process of checking that a video file meets technical specifications before it is broadcast or delivered. Pulsar does this automatically — it measures audio loudness (ensuring it meets regulatory standards such as EBU R128), checks for missing frames, validates HDR metadata, and flags subtitle timing issues. Without QC, broadcasters risk transmitting content that sounds wrong, looks wrong, or violates regulatory requirements.

IP Signal Transport & Broadcast Networking

5 systems

Modern broadcast facilities are moving from traditional copper video cables (SDI) to network-based video transport (IP). These systems manage how video and audio travel across the network — both inside a facility and between locations.

NevionIP Signal Management
VideoIPath
What it does: VideoIPath is a software system for managing IP-based video routing across a broadcast facility. Think of it as the software control panel for an IP video network. Broadcast engineers use it to define and change which video source goes to which destination — for example, routing Camera 3's feed to the replay system and also to the director's monitoring screen. It uses a broadcast industry standard called NMOS (IS-04 for discovery, IS-05 for connection management) so it can work with equipment from different vendors.

MediorNet
What it does: Riedel MediorNet is a fibre-optic distribution system that carries video, audio, data, and intercom over the same cables. In a traditional facility, video runs over coaxial cable, audio over audio cable, and intercom over telephone-style wiring. MediorNet replaces all of these with a single fibre network using SFP optical modules. Particularly popular in OB trucks where cable weight and space are critical constraints.
