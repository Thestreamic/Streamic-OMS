Audio Conform: Sending Sequences from Avid Media Composer to Pro Tools and Back

Sending a cut from Avid Media Composer to Pro Tools for audio finishing — then getting it back in sync — is one of the most frequently broken workflows in post-production. This guide walks through every step reliably.

By The Streamic Editorial Team · March 2026 · 10 min read

Why This Workflow Breaks

The Avid-to-Pro Tools interchange relies on AAF (Advanced Authoring Format), but both applications implement the spec differently. The most common failure points are: media not relinking, handles too short, audio sample rate mismatches, and timecode offset errors on return. Understanding each failure point prevents hours of manual re-sync work.

Step 1: Prepare Your Avid Sequence

Before exporting, set your sequence correctly:

  1. Lock your picture cut. Do not send an unlocked cut — any trimming after export invalidates the Pro Tools session.
  2. Check your project sample rate: File → Settings → Audio Project. Set to 48kHz, 24-bit for broadcast delivery. This must match your Pro Tools session.
  3. Flatten any audio mixdown tracks. Exported AAF must contain only the discrete audio tracks you want mixed — automation submixes will not translate.
  4. Add 2 frames of handle to each clip if your edit allows it. In the Export dialog, set Handle Length: 10 frames minimum.

Step 2: Export AAF from Avid Media Composer

  1. Select your sequence in the bin. Right-click → Export.
  2. In the Export Settings dialog, choose AAF Edit Protocol.
  3. Set Audio Details:
    • Export Method: Consolidate/Copy audio clips — this embeds media inside the AAF. Do NOT use "Link to Media" if Pro Tools is on a different machine.
    • Sample Rate: Match your project (48kHz)
    • Bit Depth: 24-bit
    • Audio Format: AIFF or BWF (Broadcast Wave). BWF is preferred for timecode embedding.
  4. Set Include All Video Tracks as Reference if you want a picture reference track in Pro Tools.
  5. Click Save and choose an export destination accessible to your Pro Tools workstation.

Common Error: "Media Not Found on Export"

This happens when your Avid project links to media on an offline or unmounted volume. Before exporting, go to Clip → Check Sequence → All Media to verify all clips are online. Reconsolidate any offline media to a local or shared drive first.

Step 3: Open in Pro Tools

  1. In Pro Tools, go to File → Open Session and select your AAF file.
  2. Pro Tools will present the AAF/OMF Import dialog:
    • Audio Media Options: Copy from Source Media — always copy, never link, for stable sessions
    • Sample Rate Conversion: Only enable if your source does not match your Pro Tools session rate
    • Handles: Set to 1 second to give your mixer flexibility
  3. Verify timecode offset. Go to Setup → Session → Timecode Settings and confirm the start TC matches your Avid sequence start timecode.

Step 4: Mix and Return to Avid

After audio finishing in Pro Tools, returning to Avid requires an AAF export of the finished session:

  1. In Pro Tools, create a new stereo audio track with your final mix. Bounce to it via Audiotrack → Bounce.
  2. Export the finished mix as a BWF file at 48kHz/24-bit, starting from the same timecode origin as your Avid sequence.
  3. In Avid, import the returned mix BWF: File → Import. Link it to your sequence at the correct timecode.
  4. Alternatively, export a full AAF from Pro Tools and open it in Avid as a new sequence for comparison.

Verifying Sync After Return

Always verify sync at three points: the first frame, a mid-sequence marker, and the last frame. Use a visible clapper or sync beep at the head of your sequence if available. Any drift beyond 1 frame indicates a sample rate conversion error — recheck your Pro Tools session rate against the BWF file metadata.

Pro Tools EUCON / S6 Note

If your facility uses an Avid S6 control surface with EUCON, ensure your Pro Tools session is set to the same work order as your Avid project. The EUCON protocol syncs transport controls but does not resolve timecode discrepancies automatically.

Broadcast Delivery Checklist

  • Final mix exported at 48kHz / 24-bit BWF with embedded timecode
  • Loudness normalised to EBU R128 (-23 LUFS integrated) for European broadcast
  • Peak level not exceeding -1 dBTP (true peak) for streaming delivery
  • Mono-compatible stereo mix: check for phase cancellation using a vectorscope
  • Separate stems delivered: dialogue, music, effects (DME) for international versioning
