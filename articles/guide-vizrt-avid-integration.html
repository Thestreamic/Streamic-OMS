Integrating Vizrt Graphics with Avid MediaCentral and iNEWS via MOS

Configure the MOS Gateway to connect Vizrt Viz Engine and Viz Pilot to Avid iNEWS and MediaCentral. Covers TCP ports, MOS IDs, story-driven graphics triggering, and common fault resolution.

By The Streamic Editorial Team · March 2026 · 16 min read

References: This guide is based on the official Avid MOS Gateway Operations Manual (v2021.7) and the Avid MediaCentral Command ICG documentation (v2019.9.1 Rev B). Refer to these documents and your Vizrt Engine documentation for version-specific parameters.

System Architecture Overview

The integration connects three systems: Avid iNEWS (newsroom computer system), Avid MediaCentral (production platform), and Vizrt Viz Engine / Viz Artist (graphics rendering). Communication follows the MOS (Media Object Server) protocol over TCP/IP.

  • MOS Gateway: The Avid component that bridges iNEWS and MOS-compliant devices (Viz Engine).
  • Viz Pilot / Viz Pilot Edge: The graphics template front-end that runs within MediaCentral UX.
  • Viz Engine: Renders graphics on-air when triggered by an iNEWS story item via MOS commands.

Step 1: Network Prerequisites

  • Viz Engine must be reachable from the MOS Gateway server. Confirm with a ping test.
  • TCP Port 10540: MOS Gateway → Viz Engine (mosPort). Must be open on the firewall.
  • TCP Port 10541: Viz Engine → MOS Gateway (callback). Must also be open.
  • TCP Port 6100: Viz Engine control port (used by Viz Pilot). Must be reachable from the Viz Pilot server.
  • If Viz Engine and MCPS are on separate VLANs, confirm routing is in place for all three ports.

Step 2: Configure Avid MOS Gateway

The MOS Gateway is configured via the MOS Gateway Configuration Tool on the MCPS server.

  • Open MOS Gateway Configuration Tool on the MediaCentral Platform Services server.
  • Add a new MOS Device entry:
    • Device Name: A unique identifier (e.g., VIZRT-MAIN)
    • MOS ID: Must match the MOS ID configured on the Viz Pilot server (e.g., VIZRT.VIZPILOT.1)
    • Hostname / IP: The IP address or FQDN of the Viz Pilot / MOS Gateway adapter
    • Lower MOS Port: 10540 (incoming from Viz)
    • Upper MOS Port: 10541 (outgoing to Viz)
  • Save and apply. The MOS Gateway service will attempt to connect to the Viz device.

Step 3: Configure Viz Pilot / Viz Pilot Edge

  • In Viz Pilot, open Configuration → MOS Settings.
  • Set MOS Server Host to the IP address of the MCPS / MOS Gateway server.
  • Set MOS ID to match exactly what you entered in the MOS Gateway configuration tool.
  • Set MOS Port to 10540.
  • Enable MOS Active Mode (Viz Pilot initiates the connection to MOS Gateway).
  • Save and restart the Viz Pilot service.

Step 4: Verify MOS Connection in iNEWS

  • In iNEWS, go to Configure → MOS Devices and confirm the Viz device appears with a green connected status.
  • If the device shows disconnected: check the MOS Gateway log on the MCPS server (C:\Program Files\Avid\MOS Gateway\logs\).
  • A successful connection log line will read: MOS connection established: [MOS ID].

Step 5: Assign Graphics Templates to Stories

  • In iNEWS, open a story. In the Story Form, select the MOS item field.
  • Double-click to open the Viz Pilot plug-in within the story editor.
  • Browse to your Viz Artist template, fill in the data fields, and click Save. The MOS item is embedded in the story.
  • In the MediaCentral rundown, the story now shows the MOS item with a Viz icon.

Step 6: Test On-Air Triggering

  • In MediaCentral, select a story with a MOS graphic item in the rundown.
  • In the Viz Pilot Edge panel (right sidebar), confirm the graphic preview renders.
  • Click Take to push the graphic to Viz Engine for preview.
  • Verify the graphic appears on the Viz Engine preview output.
  • In production, the automation system (Ross Overdrive, Grass Valley Ignite, etc.) will trigger takes automatically via the MOS protocol.

Common Issues and Fixes

  • MOS device shows disconnected in iNEWS: Check port 10540 firewall. Restart MOS Gateway service on MCPS. Check Viz Pilot MOS ID matches exactly (case-sensitive).
  • Graphics not appearing in Viz Engine: Verify port 6100 is reachable from Viz Pilot server. Check Viz Engine is in On Air state and the correct scene is loaded.
  • MOS items lost after rundown export/import: Check iNEWS story backup settings. MOS items are stored as binary blobs in iNEWS — ensure your backup includes the full story data.
  • Templates not loading in Viz Pilot Edge: Verify the Viz Pilot Edge URL in MediaCentral Settings → Viz Pilot. Check the Viz Pilot server is running and accessible on port 8080.
