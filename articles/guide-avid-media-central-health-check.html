How to Run a Health Check on Avid MediaCentral Platform Services

A MediaCentral health check should be part of every broadcast facility's daily pre-air routine. This guide covers every layer — from service status to integration endpoint verification — so issues are caught before they affect production.

By The Streamic Editorial Team · March 2026 · 12 min read

Health Check Overview: What to Verify

A complete MediaCentral health check covers six areas:

  1. MediaCentral Platform Services (MCPS) — core service status
  2. Interplay | Production connection
  3. iNEWS connection
  4. Asset browsing and proxy playback
  5. User authentication and licensing
  6. Integration endpoints (social, delivery, MAM)

Step 1: Verify Core Services via Admin Panel

All MediaCentral services are monitored through the MCPS administrator panel:

  1. Navigate to https://[server-IP]/api/als/v0 — if this returns a JSON status response, Avid License Services is running
  2. Open the MediaCentral Platform Services Administrator: https://[server]:443/mcpsadmin
  3. Go to System → Services. All core services should show Running:
    • MediaCentral Platform Services (MCPS Core)
    • Interplay Web Services
    • MediaCentral Bus
    • Avid License Service
    • Search Service
  4. Any service showing Stopped or Error should be restarted from the panel — click the service → Restart

Command-Line Alternative (Linux Server)

sudo systemctl status avid-mcs
sudo systemctl status avid-license-service
sudo systemctl status avid-interplay-ws

Step 2: Verify Interplay | Production Connection

  1. In the MCPS Admin panel, go to Connections → Interplay | Production
  2. Verify the connection shows Connected with the correct Interplay Engine hostname or IP
  3. Click Test Connection — response time should be under 500ms on a LAN
  4. If the test fails: check that the Interplay Engine service is running on the Interplay server, and that port TCP 8321 is open between MCPS and Interplay Engine

Step 3: Verify iNEWS Connection

  1. In MCPS Admin, go to Connections → iNEWS
  2. Confirm the connection shows the correct iNEWS server address and Connected status
  3. Open MediaCentral Cloud UX and browse to any active rundown — stories should load within 3 seconds
  4. If stories appear blank or "Loading..." indefinitely, the iNEWS NRCS connection has dropped. Restart the iNEWS System Service on the iNEWS server, then restart the iNEWS connection in MCPS Admin

Step 4: Test Asset Browsing and Proxy Playback

Asset browsing validates the full chain from MediaCentral UI through Interplay Web Services to the Avid ISIS shared storage:

  1. Log in to MediaCentral Cloud UX as a standard user (not admin)
  2. Browse to a known asset in the Interplay | Production section
  3. Verify: thumbnail displays within 5 seconds
  4. Click play — proxy video should begin playback within 3 seconds
  5. Scrub to mid-sequence and verify audio sync

If thumbnails fail: the proxy cache service may be overloaded. Check disk space on the MediaCentral server — proxy storage requires a minimum 20% free space to generate new proxies.

Step 5: Verify Licensing

  1. In MCPS Admin, go to System → Licenses
  2. Confirm licence count shows available seats. If all seats are consumed, new users cannot log in
  3. Check licence expiry dates — expired licences drop silently and cause intermittent login failures
  4. If you see "No licence available": go to System → Active Sessions and clear any stale sessions from users who have disconnected without logging out

Step 6: Check System Logs for Errors

The most useful logs for broadcast facilities are:

  • MCPS Core log: /var/log/avid/mcps/mcps.log — look for ERROR or FATAL entries within the last 24 hours
  • Interplay Web Services log: /var/log/avid/interplay-ws/ — connection failures to Interplay Engine appear here
  • Transfer Engine log: C:\ProgramData\Avid\Avid Interplay Transfer Engine\Logs\ (Windows) — proxy generation failures are logged here
# Quick error check — last 100 MCPS log lines
sudo tail -100 /var/log/avid/mcps/mcps.log | grep -E "ERROR|FATAL|WARN"

Pre-Air Health Check Checklist

  • All MCPS services: Running ✓
  • Interplay connection: Connected, response <500ms ✓
  • iNEWS connection: Connected, stories loading ✓
  • Asset browser: Thumbnails and proxies loading ✓
  • Licence seats: >10% available ✓
  • Disk space on MCPS server: >20% free ✓
  • No ERROR entries in MCPS log in last 2 hours ✓
